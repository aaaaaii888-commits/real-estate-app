# 不動産査定・現地内覧調査アプリ

不動産の実務査定・現地内覧時に、片手でサクサク確認項目を入力し、その場で査定報告書（PDF）を作成できるWebアプリ（PWA対応）です。

---

## 🌟 主な機能・特徴

1. **物件種別の切り替え（初期選択）**
   - **マンション（区分）** / **一戸建て** / **土地** / **一棟アパート・ビル**
   - 種別を選択するだけで、それぞれの特性に応じたチェックリストが自動展開されます。

2. **登記簿表題部 ＆ 現況基本情報**
   - 地番、家屋番号、地目・種類、構造、床面積/地積、築年数
   - 使用状況（居住中/空室/賃貸中など）、売却・査定希望価格、調査日、担当者名

3. **現場用スマートチェックシート（スマホ片手操作に最適化）**
   - **ワンタップ3択判定**: 「◎ 良好 / ◯ 普通 / △ 要修繕」を片手でタップ。
   - **現場写真添付**: 各項目ごとにスマホカメラを起動してその場で写真を撮影・添付可能。
   - **特記メモ**: 気になる箇所（壁紙の剥がれ、給湯器交換年など）をサッと入力。
   - **重要確認事項を標準装備**:
     - リフォーム・修繕履歴
     - 告知事項の有無（心理的瑕疵、雨漏り、シロアリ等）
     - 越境の有無（塀、樹木、雨樋等）
     - 暖房給湯の熱源（都市ガス / LPガス / オール電化 / 灯油）
     - 暖房機器・エアコンの有無
     - 残置物の有無

4. **査定内覧報告書の作成・PDF出力 / 印刷**
   - 入力した結果から、A4用紙サイズに最適化されたプロ仕様の「査定内覧調査報告書」を即時生成。
   - 要修繕や重要告知事項がある場合は、上部に黄色ハイライトで自動ピックアップ。
   - ブラウザの印刷ダイアログから「PDFとして保存」またはそのままA4用紙に印刷可能。

5. **自動保存（オフライン対応）**
   - 入力データは端末のブラウザ（LocalStorage）にリアルタイムで自動保存されるため、電波が届きにくい室内でも安心です。

---

## 📱 スマホで開く・アプリ化する方法

1. **PCと同じWi-Fi環境のスマホからアクセスする場合**
   - PC側で簡単なローカルWebサーバーを起動し、表示されたローカルIPアドレス（例: `http://192.168.x.x:8080`）をスマホのブラウザで開きます。
2. **iPhone (Safari) でアプリ化**:
   - 画面下の「共有ボタン（四角から矢印）」をタップ ➜ **「ホーム画面に追加」** を選択。
   - ホーム画面にアイコンが追加され、全画面のネイティブアプリとして起動できます。
3. **Android (Chrome) でアプリ化**:
   - 画面右上のメニュー（3点リーダー）をタップ ➜ **「ホーム画面に追加」** または **「アプリをインストール」** を選択。
